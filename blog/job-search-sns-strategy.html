취업 준비에 SNS가 필요한 이유

취업 준비에서 SNS를 제대로 활용하는 사람과 그렇지 않은 사람의 정보 격차는 생각보다 큽니다. 링크드인 하나로 직접 연락을 받는 경우도 있고, 블라인드에서 실제 면접 후기를 찾아 합격하는 경우도 있습니다.

링크드인 — 채용담당자가 직접 보는 플랫폼

프로필 핵심 3가지

  • 헤드라인 — "OO대학교 경영학과"보다 "데이터 기반 마케팅을 공부하는 취준생 | GA4·SQL 활용"처럼 역량 중심으로
  • 소개(About) — 자소서 자기소개 요약본. 300자 이내로 핵심만
  • 경험(Experience) — 인턴, 아르바이트도 포함. 각 경험마다 3줄 이내로 성과 기술

링크드인 적극 활용법

  • 지원 회사 재직자 프로필 검색 → 실제 업무 파악
  • 채용담당자 팔로우 → 채용 공고 알림 수신
  • 지원 직무 관련 콘텐츠 작성 → 노출도 증가

블라인드 — 현직자의 솔직한 이야기

블라인드는 현직자들이 익명으로 솔직하게 회사 이야기를 하는 플랫폼입니다. 면접 준비에서 특히 유용합니다.

활용법

  • 면접 후기 검색 — "[회사명] 면접"으로 검색. 실제 면접 질문과 분위기 파악
  • 회사 문화 파악 — 장단점, 퇴사 이유 등 현실적인 정보
  • 연봉 정보 — 직군별 실제 연봉 확인

단, 블라인드는 불만족한 직원의 비율이 높아 편향될 수 있습니다. 여러 후기를 종합해서 판단하세요.

잡플래닛 — 면접 후기와 기업 정보

잡플래닛은 면접 후기가 가장 잘 정리된 플랫폼입니다.

활용법

  • 면접 후기 — 실제 면접 질문, 난이도, 분위기 확인. 면접 준비에 직접 활용 가능
  • 기업 리뷰 — 복지, 워라밸, 성장 가능성 파악
  • 합격 스펙 — 합격자들의 학력, 경력, 스펙 참고

사람인·잡코리아 — 채용 공고 외에도 활용

  • 연봉 정보 — 직군별 평균 연봉 확인
  • 기업 정보 — 규모, 업력, 주요 사업 파악
  • 합격 자소서 — 실제 합격자 자소서 참고 (유료)

SNS 활용 시 주의할 것

  • 링크드인에 올리는 콘텐츠는 전문적으로 — 개인 SNS와 구분
  • 블라인드 후기는 참고용, 절대적 기준으로 삼지 말 것
  • SNS 서핑이 취준 시간을 잡아먹지 않도록 시간 제한 설정
