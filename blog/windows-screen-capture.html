윈도우 캡처 단축키 정리 (Win+Shift+S 부분 캡처·저장 위치·안될 때)

좋은 취업 · 15년차 인사담당자2026-11-28
핵심 답변윈도우에서 가장 많이 쓰는 캡처 단축키는 Windows 로고 키+Shift+S입니다. 화면이 어두워지면 원하는 영역을 드래그하고, 캡처된 이미지는 클립보드에 들어가므로 Ctrl+V로 바로 붙여 넣습니다. 전체 화면을 파일로 저장하려면 Windows 로고 키+PrtSc(사진 > 스크린샷 폴더)를 씁니다.

보고서에 화면을 붙이거나 오류 화면을 IT 담당에게 보낼 때 매일 쓰는 기능입니다. 단축키별 차이와 저장 위치, 캡처가 안 될 때 확인할 것을 정리했습니다.

1. 윈도우 캡처 단축키 한눈에 보기

단축키캡처 범위결과
Win+Shift+S영역·창·전체 선택클립보드 + 캡처 도구 알림
Win+PrtSc전체 화면사진\스크린샷 폴더에 파일 저장
Alt+PrtSc지금 쓰는 창클립보드
PrtSc전체 화면클립보드 또는 캡처 도구(설정에 따라)
Win+Shift+R선택 영역 녹화동영상(Windows 11 캡처 도구)

2. Win+Shift+S 부분 캡처는 어떻게 쓰나요?

  1. 캡처할 화면을 띄워 두고 Windows 로고 키+Shift+S를 누릅니다.
  2. 화면이 어두워지고 위쪽에 도구 막대가 뜹니다. 사각형·자유형·창·전체 화면 중 하나를 고릅니다.
  3. 영역을 드래그하면 클립보드에 복사됩니다. 메신저·메일·PPT에 Ctrl+V로 붙여 넣습니다.
  4. 표시를 하거나 파일로 남기려면 오른쪽 아래 알림을 눌러 캡처 도구에서 편집 후 Ctrl+S로 저장합니다.

메뉴를 펼친 상태를 찍어야 한다면 캡처 도구의 지연 캡처(몇 초 뒤 캡처)를 쓰면 됩니다.

3. 캡처 이미지는 어디에 저장되나요?

  • Win+Shift+S, Alt+PrtSc: 파일이 아니라 클립보드에 들어갑니다. 붙여 넣거나 캡처 도구에서 따로 저장해야 남습니다.
  • Win+PrtSc: 내 PC > 사진 > 스크린샷 폴더에 자동으로 저장됩니다.

Windows 11 캡처 도구는 설정에 따라 캡처한 이미지를 자동 저장하기도 하니, 캡처 도구 설정에서 저장 옵션을 확인하세요.

4. 창만 캡처·화면 녹화는?

Alt+PrtSc는 지금 선택된 창만 클립보드에 복사합니다. 모니터를 두 대 쓸 때 한쪽 화면 전체가 찍히는 걸 피하기 좋습니다(모니터 2대 연결방법 참고). 동작을 보여줘야 할 때는 Windows 로고 키+Shift+R로 캡처 도구 녹화를 시작하고 영역을 지정합니다.

5. 캡처가 안 될 때

  • 노트북 PrtSc가 반응 없음: PrtSc가 다른 기능과 같은 키에 있으면 Fn을 같이 눌러야 합니다.
  • Win+Shift+S가 안 먹힘: 시작 메뉴에서 '캡처 도구'를 검색해 직접 실행해 봅니다. 앱이 열리지 않으면 Windows 업데이트 후 재시작합니다.
  • 검은 화면만 찍힘: 동영상·보안 프로그램·일부 업무 시스템은 캡처를 막아 두는 경우가 있습니다. 회사 보안 정책일 수 있으니 IT 담당에게 확인합니다.

단축키를 더 익히고 싶다면 엑셀 단축키 정리표도 함께 보세요.

출처
  • Microsoft 지원 「창 또는 화면 내용 복사」 — Windows 로고 키+Shift+S, 캡처 도구
  • Microsoft 지원 「캡처 도구 사용」 — 캡처 도구 여는 방법, Ctrl+C 복사, Ctrl+S 저장, 지연 캡처
  • 삼성전자서비스 화면 캡처 안내 — Win+PrtSc 스크린샷 폴더 저장, 노트북 Fn 키
