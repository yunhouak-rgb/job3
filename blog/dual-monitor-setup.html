모니터 2대 연결방법 (노트북·데스크톱 설정, 확장·마우스 이동·인식 안 될 때)

좋은 취업 · 15년차 인사담당자2026-11-28

이 글에는 쿠팡 파트너스 링크가 있으며, 이를 통해 구매하면 일정액의 수수료를 받습니다.

핵심 답변모니터 2대 연결은 ① 포트에 맞는 케이블로 연결 → ② Windows 키+P에서 '확장' 선택 → ③ 설정 > 시스템 > 디스플레이에서 [식별] 후 모니터 그림을 실제 배치대로 끌어 놓고 [적용] 순서입니다. 마우스가 엉뚱한 쪽으로 넘어가는 문제는 ③의 재정렬로 해결됩니다.

재택이든 사무실이든 모니터를 하나 더 붙이면 자료를 띄워 놓고 문서를 쓰는 일이 훨씬 편해집니다. 다만 케이블을 꽂았는데 같은 화면만 나오거나, 마우스가 반대쪽으로 넘어가거나, 아예 인식이 안 되는 경우가 많습니다. Windows 11/10 기준으로 순서대로 정리했습니다.

1. 연결 전에 포트와 케이블부터 확인

컴퓨터의 영상 출력 단자와 모니터 입력 단자를 먼저 보고 케이블을 고릅니다. 흔히 쓰는 단자는 HDMI, DisplayPort(DP), USB-C입니다.

  • HDMI — 노트북·모니터 대부분에 있는 단자입니다.
  • DisplayPort·Mini DisplayPort — 데스크톱 그래픽카드와 일부 노트북에 있습니다.
  • USB-C — 모든 USB-C가 화면 출력을 지원하지는 않습니다. 노트북 사양에서 디스플레이 출력 지원 여부를 확인하세요.

케이블이 없다면 양쪽 단자가 같은 HDMI 케이블이 가장 무난합니다. 예: 벨킨 HDMI 2.1 케이블 2m. 노트북 화면 + 외부 모니터 1대가 아니라 외부 모니터 2대를 쓰려면 노트북에 영상 출력 포트가 두 개 있거나 도킹 스테이션이 필요합니다.

2. Windows 키+P로 확장 설정

케이블을 꽂은 뒤 Windows 키+P를 누르고 '확장'을 고릅니다.

메뉴화면이 어떻게 나오나언제 쓰나
PC 화면만한 화면에만 표시외부 모니터를 잠시 끌 때
복제두 화면에 같은 내용발표·화면 공유
확장두 화면을 이어서 넓게 사용업무용 듀얼 모니터
두 번째 화면만외부 모니터에만 표시노트북을 덮고 쓸 때

창을 다른 모니터로 옮길 때는 창을 끌어도 되고, Windows 키+Shift+왼쪽/오른쪽 화살표를 누르면 바로 넘어갑니다.

3. 모니터 2대 마우스 이동 방향 맞추기

마우스가 오른쪽으로 가야 하는데 왼쪽으로 넘어간다면 화면 배치 순서가 실제와 다르게 잡힌 것입니다.

  1. 바탕화면에서 마우스 오른쪽 버튼 → 디스플레이 설정(설정 > 시스템 > 디스플레이)
  2. [식별]을 누르면 각 모니터에 번호가 크게 뜹니다.
  3. 설정 화면의 모니터 그림을 실제 책상 위 배치대로 끌어다 놓고 [적용]을 누릅니다.

두 모니터의 높이가 다르면 그림의 위아래 위치도 맞춰 주세요. 모서리에서 마우스가 걸리는 현상이 줄어듭니다.

4. 주 모니터·해상도·배율 설정

  • 주 모니터 — 디스플레이 설정에서 모니터를 고른 뒤 '이 디스플레이를 주 모니터로 만들기'를 체크하면 작업 표시줄 아이콘과 새 창이 그 모니터에 열립니다.
  • 해상도 — 모니터를 고른 뒤 [디스플레이 해상도]에서 '권장'을 고르는 것이 기본입니다.
  • 배율(크기 조정) — 글씨가 너무 작거나 크면 [크기 조정]에서 바꿉니다. 모니터마다 따로 설정됩니다.
  • 방향 — 모니터를 세로로 세워 문서를 길게 보려면 [디스플레이 방향]을 '세로'로 바꾸고 모니터도 실제로 돌려야 합니다.

5. 모니터 2대가 인식 안 될 때

  1. Windows 키+P에서 '확장'인지 다시 확인합니다.
  2. 디스플레이 설정 > 여러 디스플레이 > [감지]를 누릅니다.
  3. 케이블을 양쪽 다 다시 꽂고, 모니터 메뉴에서 입력 소스(HDMI1·DP 등)가 꽂은 단자와 같은지 확인합니다.
  4. 설정 > Windows 업데이트에서 업데이트와 드라이버를 최신으로 맞춥니다.
  5. 외부 모니터 1대는 되는데 2대가 안 되면, 그래픽 장치가 지원하는 모니터 수나 영상 출력 포트 개수의 한계일 수 있습니다.

6. 모니터 2대 배치, 높이는 어떻게?

자주 보는 모니터를 정면에, 보조 모니터를 옆에 두고 두 화면 높이를 눈높이에 맞추는 것이 기본입니다. 고용노동부 VDT 작업관리지침은 화면 상단이 눈높이와 비슷하고, 눈과 화면 거리가 40cm 이상이 되도록 권합니다. 두 대를 같은 높이로 맞추기 어렵다면 모니터암이나 받침대를 씁니다. 예: 카멜 듀얼 모니터암, 메탈 모니터 받침대. 자세 기준은 사무실 의자 바른 자세에 정리했습니다.
