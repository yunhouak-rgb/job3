프린터 오프라인 해결 (Windows 11 온라인 변경·인쇄 대기열 정리 순서)

좋은 취업 · 15년차 인사담당자2026-11-28
핵심 답변프린터가 켜져 있는데 오프라인으로 뜨면 ① 프린터 전원 껐다 켜기 → ② 케이블·Wi‑Fi 연결 확인 → ③ '오프라인으로 프린터 사용' 체크 해제 → ④ 인쇄 대기열 모두 취소 → ⑤ 기본 프린터 확인·PC 재시작 → ⑥ 문제 해결사·드라이버 재설치 순서로 해 보세요. 대부분 ①~④에서 풀립니다.

급하게 출력해야 할 때 '오프라인' 표시가 뜨면 당황스럽습니다. 오프라인은 대개 PC가 프린터와 통신하지 못한다는 뜻이라, 연결과 설정을 순서대로 확인하면 됩니다. Windows 11 기준입니다.

📑 목차
  1. 프린터 전원 껐다 켜기
  2. 연결 확인: USB·Wi‑Fi
  3. 오프라인으로 프린터 사용 해제
  4. 인쇄 대기열 비우기
  5. 기본 프린터·PC 재시작
  6. 그래도 안 되면: 문제 해결사·재설치

1. 프린터 전원부터 껐다 켜기

프린터를 끄고 플러그를 뺀 뒤 30초 정도 기다렸다가 다시 연결하고 켭니다. Microsoft 안내에서도 첫 단계로 권하는 방법입니다. 프린터 화면에 용지 걸림·잉크·토너 오류가 떠 있다면 그것부터 해결합니다.

2. 연결 확인: USB·Wi‑Fi

  • USB 프린터: 케이블이 양쪽에 제대로 꽂혀 있는지, 다른 USB 포트에 꽂아도 같은지 확인합니다. 허브를 거친다면 PC에 직접 꽂아 봅니다.
  • 무선 프린터: 프린터와 PC가 같은 Wi‑Fi에 연결돼 있는지 확인합니다. 공유기를 바꿨거나 재부팅한 뒤에는 프린터 IP가 바뀌어 PC가 찾지 못하는 경우가 있습니다. 프린터 설정 화면에서 네트워크 연결 상태를 확인합니다.

3. '오프라인으로 프린터 사용' 해제

  1. 시작 > 설정 > Bluetooth 및 장치 > 프린터 및 스캐너로 갑니다.
  2. 해당 프린터를 누르고 인쇄 대기열 열기를 선택합니다.
  3. 창 위쪽 메뉴(… 또는 '프린터')에서 오프라인으로 프린터 사용에 체크가 되어 있으면 눌러서 해제합니다.

이 옵션이 켜져 있으면 프린터가 멀쩡해도 계속 오프라인으로 표시됩니다.

4. 인쇄 대기열 비우기

앞에서 실패한 인쇄 작업이 대기열에 걸려 있으면 뒤 작업이 모두 막힙니다. 인쇄 대기열 창에서 …(더보기) > 모두 취소를 누릅니다. 취소가 안 되고 남아 있으면 PC를 재시작합니다.

5. 기본 프린터 확인·PC 재시작

프린터 및 스캐너 화면에서 지금 쓰려는 프린터를 기본값으로 설정합니다. 버튼이 안 보이면 'Windows에서 기본 프린터를 관리하도록 허용'을 끄면 나타납니다. 같은 프린터가 '(사본 1)'처럼 두 개 보이면 엉뚱한 쪽으로 인쇄를 보내고 있는 경우가 많습니다. 그다음 PC를 다시 시작해 통신 서비스를 새로 고칩니다.

6. 그래도 안 되면: 문제 해결사·드라이버 재설치

  • 문제 해결사: Windows 11은 '도움말 보기' 앱의 프린터 문제 해결사가 자동으로 진단합니다.
  • 프린터 제거 후 다시 추가: 프린터 및 스캐너에서 해당 프린터를 제거하고 '장치 추가'로 다시 추가합니다.
  • 제조사 드라이버: 프린터 제조사 홈페이지에서 모델명으로 최신 드라이버를 받아 설치합니다.

회사 공용 프린터라면 IP·드라이버를 IT 담당이 관리하는 경우가 많으니 재설치 전에 확인하세요. PC 자체가 느려서 인쇄 창이 늦게 뜬다면 노트북 느려짐 해결도 함께 보세요.
